Strategy — “Momentum Rider” (v1)

  • Signal: LONG when fast SMA(12) > slow SMA(48) and RSI(14) > 55. Flat when SMA flips or RSI(14) < 45. Long/flat only — no shorts in v1.
  • Sizing: risk 1% of capital per trade; stop = entry − 2× ATR(14); take-profit = entry + 3× ATR(14); max position 25% of capital.
  • Guardrails: daily loss limit 2% (halt entries for the day); max-drawdown circuit breaker at 5% (flatten + 48h cooldown, then resume).
  • Costs modeled: 0.10% taker fee + 0.05% slippage per fill.
  • Data: CoinGecko public price API (live, no key) with a deterministic seeded mock feed as fallback and for backtests.

Run it

git clone https://github.com/Anyeps/oobe-capital-agent.git
cd oobe-capital-agent
npm install
npm test            # 10 unit tests
npm run backtest    # 90-day paper backtest (deterministic, seed 42)
npm run live        # live paper trading (read-only CoinGecko prices)
npm run mcp         # MCP server (stdio): 85 OOBE Synapse tools
